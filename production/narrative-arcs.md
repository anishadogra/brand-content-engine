# Narrative Arcs

Every {{brand.name}} carousel must read as one connected story, not 5 disconnected facts. Pick an arc that matches the brief, then sequence templates onto it.

**Connection rule:** each slide should set up a question or curiosity that the next slide pays off.

## A. Single Product Spotlight (default)
**Use when:** Pushing one SKU.
**Slides (5):** `hero` → `quote` → `proof` → `recipe` → `cta`
**Bg rhythm:** cream → burgundy → cream → mustard → cream
**Story:** "Meet X." → "This is how it tastes." → "And here's why it's different." → "And here's how to use it." → "Follow for more."

## B. Hot/Spicy Product Spotlight
**Use when:** Pushing a heat-forward SKU ({{sku.heat_1}}, {{sku.heat_2}}).
**Slides (5):** `hero` → `quote` → `proof` → `difference` → `cta`
**Bg rhythm:** cream → deep_maroon → cream → red → cream
**Story:** Hook on heat → taste credential → protein truth → why our heat is real → CTA

## C. Origin / Heritage Spotlight
**Use when:** SKU has a strong cultural/regional story ({{sku.heritage_2}}, {{sku.heritage_1}}, French {{sku.heritage_4}}, {{sku.heritage_3}}).
**Slides (5):** `hero` → `origin` → `proof` → `difference` → `cta`
**Bg rhythm:** cream → burgundy → cream → red → cream
**Story:** Hero hook → "where it comes from" → "the truth about the macros" → "why our version" → CTA

## D. Recipe / Pairing
**Use when:** Cooking, drinks, hosting, snacking ideas.
**Slides (5):** `hero` → `recipe` → `recipe` → `proof` → `cta`
**Story:** Hook → 3 ways → 3 more ways → why it's good for you → CTA

## E. Category Explainer
**Use when:** Educating the market on what the product category actually IS.
**Slides (5):** `hero` → `origin` → `proof` → `range` → `cta`
**Bg rhythm:** cream → burgundy → cream → cream → cream
**Story:** "What is a {{product.line_a}}?" → "Older than you think." → "Better protein than you think." → "And we make 7 flavours." → CTA

## F. Range / Family
**Use when:** Showing the whole line (PC's 7 SKUs or PB's 4 SKUs).
**Slides (5):** `hero` → `range` → `quote` → `proof` → `cta`
**Story:** Hook → see the family → taste promise → protein credential → CTA

## G. Myth-Bust / FAQ
**Use when:** Tackling objections (is it healthy? is it deep-fried? is it gluten-free?)
**Slides (5):** `hero` (the myth) → `quote` (the truth) → `proof` (data) → `difference` (4 facts) → `cta`
**Story:** "Wait, {{product.line_a}} is good for you?" → "Yes." → "Here's why." → "And here's what makes ours different." → CTA

## H. New Drop / Launch
**Use when:** Announcing a new SKU.
**Slides (5):** `hero` (NEW IN THE BAG) → `quote` (taste note) → `proof` → `range` (where it sits) → `cta`

## Bg rhythm rules

- Always alternate intensity. Avoid two same-bg slides in a row UNLESS for narrative effect.
- Cream is the "rest" colour; red and burgundy are "punch" colours; mustard/coral/deep_maroon are accents.
- The CTA should be on cream so the handle reads cleanly.

## Headline colour-split

Hero / proof / difference / etc. headlines split across two parts: `h1` in `ink` colour, `h2` in `accent` colour. The split emphasises the noun.
- On cream bg: ink = burgundy, accent = red
- On red bg: ink = cream, accent = mustard
- On burgundy bg: ink = cream, accent = mustard
- On mustard bg: ink = burgundy, accent = red
- On deep_maroon bg: ink = cream, accent = mustard
